Scope is the approved BudgetBranch contracts tree `2c691ebdbd23e9d9e22ea67fc3aa22c9b5226106` on local `main` at `4de180536eb75ebf3d653c063ef20ef7ba6dadc8`. The inspected `contracts/Cargo.lock` SHA-256 is `b3c1f6f3287d4864b308f6907153dfbf52feb5e30e240725a7370dc91bb0c86a`. The review concerns the release's source checkout and gives separate considerations for any future binary distribution. It is an engineering review of the recorded artifacts and scope.

## Inventory and artifact scope

- The lockfile has 442 packages, including four local workspace packages. All 438 external crates are pinned by the official crates.io registry and a SHA-256 digest. The initial cache check found no missing archives or extracted sources. The offline Cargo metadata contains the same 442 packages. The audit hashed every cached archive and compared it to the lockfile, inspected every archive's normalized manifest and the corresponding local copy, and hashed 763 named license or notice files. The JSON records exact package version, download URL, checksum, original repository and VCS metadata when supplied, declared SPDX or legacy expression, archived file paths and hashes, sampled copyright and license headers, and graph membership. Header sampling does not establish authorship or applicability for every file. [Inventory](cargo-inventory.json) · [Initial cache check](missing-first.json).
- The `budgetbranch` and `demo-receiver` Wasm normal target graph contains the same 36 external crates. The `cargo tree -e normal,no-proc-macro` result matches all 36 crate source identities recorded in the target `.d` files from the clean G3 build. There are 71 external crates in the broader normal-and-build graph including host build dependencies and procedural macros. These lists identify Cargo target/build libraries and sources. LTO may exclude unreachable code and procedural macros may generate code. The inventory excludes Rust's sysroot. [Wasm target tree](budgetbranch-wasm-normal-no-proc-tree.txt) · [Build graph](budgetbranch-wasm-normal-build-tree.txt).

Apache-2.0 distribution also calls for preserving applicable notices, including a `NOTICE` file when supplied. [Apache-2.0 §4](https://www.apache.org/licenses/LICENSE-2.0) · [Original foldhash license](notices/foldhash-0.2.0-Zlib.txt).

## Wasm obligations and missing license files

Both packages declare MPL-2.0 only. If distributing the compiled Wasm, make the exact corresponding MPL-covered source files and any modifications available under MPL-2.0 and tell recipients how to obtain them. Preserve existing license and copyright notices. MPL's file scope allows other, separable files to retain their own terms. These Rust dependencies remain under MPL when BudgetBranch's original source is offered under MIT OR Apache-2.0. [Mozilla MPL §§3.1–3.4](https://www.mozilla.org/en-US/MPL/2.0/) · [Mozilla distributor FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).

## Prebuilt nearcore Sandbox executable

The project bootstrap downloads the Darwin ARM64 `near-sandbox` **executable** from NEAR's official artifact host. The cached launcher crate's runner code specifies this host and target naming. The archive SHA-256 is `ea53448ef97540c012e5c3d967c74d78292b0465a98cf7027811a936718fe232`. The executable SHA-256 is `8e0e1521372b0fce801b7464078c1e95e5a25a0f92ad4b4241451c33fe9e5a2a`. Those are observed project pins. The archive contains only `Darwin-arm64/near-sandbox`. The executable reported nearcore 2.14.0, commit `bc4e9e8cfb03d9e82f027883055624e18576993e` and protocol 88. The upstream release tag has the same commit and its `neard` package inherits workspace `MIT OR Apache-2.0`. Tagged source contains `licenses/LICENSE-MIT` and `licenses/LICENSE-APACHE`. BudgetBranch's `Cargo.lock` does not resolve this separate executable's build graph. Artifact provenance and the workspace declaration do not establish the complete binary dependency or notice list. Maintain the download-from-upstream source-only distribution boundary unless binary attribution, linked components and notices are separately verified. [Official nearcore 2.14.0 release](https://github.com/near/nearcore/releases/tag/2.14.0) · [Tagged workspace manifest](https://raw.githubusercontent.com/near/nearcore/2.14.0/Cargo.toml) · [Tagged executable manifest](https://raw.githubusercontent.com/near/nearcore/2.14.0/neard/Cargo.toml) · [Artifact](https://s3-us-west-1.amazonaws.com/build.nearprotocol.com/nearcore/Darwin-arm64/2.14.0/near-sandbox.tar.gz).

The source checkout currently tracks no `.wasm`, `.crate`, `near-sandbox` executable or vendored Cargo registry. The owner's MIT OR Apache-2.0 choice covers original separable BudgetBranch files. Applicable upstream license texts and notices follow the dependencies if distributed. No runtime, contract, lockfile or tracked documentation was changed by this review.
